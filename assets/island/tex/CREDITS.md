# assets/island/tex: the shared material library (PUMPFUN PIRATES)

`lib.ktx2` (desktop, 12 x 1024 px) and `lib_lo.ktx2` (phones, 12 x 512 px) are 2D-array KTX2 textures (Basis ETC1S + mips) built by
`tools/plaza_blender/make_textures.py` from CC0 photo sources, regraded locally (painted median + high-pass flatten + neutral
grade; the vertex colour carries the hue). No AI-generated imagery.
